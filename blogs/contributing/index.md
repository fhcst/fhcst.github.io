# 學生協作指南

本指南協助老師與學生共同維護 **FHCST 山城資訊工作隊的官方網站及 blog**。

你不需要一次學完 Git。第一次參與的目標，是完成一個小修改，讓另一位同學看得懂你的變更，並能確認它正確。

本指南搭配儲存庫的[貢獻規則](https://github.com/fhcst/fhcst.github.io/blob/main/CONTRIBUTING.md)使用。一般學生使用 Fork＋PR，由 [@Na2CO32](https://github.com/Na2CO32) 正式審查並合併；Na2CO32 自己的 PR 由 **CXPhoenix** 審查。安全或行為問題請透過課程既有私下管道聯絡 CXPhoenix。

## 建議閱讀順序

1. [環境與第一次啟動](getting-started.md)：安裝工具，看到本機網站。
2. [Git 協作流程](workflow.md)：認領任務、建立分支、提交 PR 與回應審查。
3. [內容與素材規範](content-style.md)：找到該改的檔案，處理文字、圖片與個資。
4. [授權與署名](licensing.md)：了解 CC BY-NC-SA 4.0，以及如何交代來源。
5. [維護者檢查表](maintainers.md)：負責審查、合併或交接時使用。

## 第一次交付的完成條件

- 有明確的小任務，知道誰會協助審查。
- 在自己的工作分支修改，沒有混入同學的變更。
- 能說明改了什麼、為什麼要改、如何確認。
- PR 如實記錄建置與預覽結果；還沒完成的項目保持未勾選。
- 回應審查意見，由維護者完成合併與部署確認。

Fork＋PR 與人員分工已由負責人確認；規則導入與待決事項記錄於 [PROJECT.md](https://github.com/fhcst/fhcst.github.io/blob/main/PROJECT.md)。

## 不知道下一步時

一般操作問題依[求助說明](https://github.com/fhcst/fhcst.github.io/blob/main/SUPPORT.md)開 Issue。若看到密碼、個資或漏洞，依[安全政策](https://github.com/fhcst/fhcst.github.io/blob/main/SECURITY.md)私下回報，不把敏感內容公開貼出來。
