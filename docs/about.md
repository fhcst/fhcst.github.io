# 關於我們

CST 團隊成立於 2024 年，一開始只是幾位同學在課後一起做專案，
後來逐漸發展成一支跨領域的小型團隊，專注於網站與應用程式的設計與開發。

## 我們的使命

> 用技術解決真實問題，讓每個人都能輕鬆使用好的數位服務。

## 我們在做什麼

- **網站與 Web App 開發**：從需求訪談、設計到上線一條龍。
- **UI / UX 設計**：使用者研究、原型設計與介面優化。
- **技術顧問**：協助團隊導入現代化的開發流程與工具。
